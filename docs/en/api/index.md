# Documentation

## The `pyflix` package
The `pyflix` package provides resources for *fundamental* and *advanced* training courses.

 - The [datasource](pyflixdatasource.md) module will be used for the activities.
 - The [loaders](loaders.md) package allows you to load data from CSV or media files.
 - The [utils](utils.md) package provides functions for displaying data structures created during the training.
 - The [utils](utils.md) package provides functions to display the data structures
   created during the training.

## The `pyacademy` package
The `pyacademy` package provides resources for *advanced* training courses.
