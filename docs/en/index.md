# Pyschool-lib

## Introduction
This project is intended for my training courses and has two objectives:

 * to illustrate the packaging of a Python project
 * to provide a library of resources for the activities.

You will therefore find:

 * [Installation documentation](installation.md) if you just need to use the resources.
 * Documentation on the [packaging](package.md) of this project.
 * Documentation of the [resources](api/index.md) provided by this project.

This documentation is currently being written. You can find the various elements in the
navigation menu.
