# Documentation du module pyflix.datasource

Ce module est destiné à vous fournir des ressources lors des exercices. Cette page fournit la
documentation des différentes fonctions. Toutes les fonctions ne sont pas citées lors des exercices
mais pourront vous aider à avoir des données alternatives pour vérifier le bon fonctionnement de vos
propositions.

Une page [d'exemples d'usage](../tutos/data_load.md) vous permet de voir comment utiliser ces
fonctions.
