# Documentation

## Le package `pyflix`
Le package `pyflix` fournit des ressources pour les formations *fondamentaux* et *perfectionnement*.

 - Le module [datasource](pyflixdatasource.md) sera utilisé pour des exercices.
 - Le package [loaders](loaders.md) permet de charger des données à partir de fichiers csv ou
   média.
 - Le package [utils](utils.md) fournit des fonctions pour afficher les structures de données
   créées pendant la formation.

## Le package `pyacademy`
Le package `pyacademy` fournit des ressources pour les formations *perfectionnement*.
